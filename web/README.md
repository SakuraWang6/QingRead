# 清读 Web

面向手机浏览器的清读阅读器，桌面也可使用。React + TypeScript 前端与 Node 书源服务放在同一目录；iOS 原生版继续独立维护。

当前 Web 源码为 0.12.0，API 沿用 0.10.0，Android 源码为 0.12.0/versionCode 12；交付状态见[验证记录](../docs/verification.md)。服务端可自行部署；个人数据通过可选用户名与密码账号同步。源码不预设作者服务器，配置见 [部署说明](deploy/README.md) 和 [云同步](../docs/cloud-sync.md)。

## 本地运行

需要 Node.js 24、npm（使用内置 SQLite）与 Python 3.10+（生成共用版本清单）。在本目录执行：

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173>。该命令同时启动网页与书源服务，Vite 将 `/api` 请求转给 `127.0.0.1:8787`。终端保持运行；按 `Ctrl+C` 停止。开发模式默认只允许这台电脑访问。

初始书架包含明确标记为“本地公版”的《桃花源记》，可直接体验阅读。联网搜书需要书源服务与原书库可访问。搜索结果分批出现；搜索期间点击“取消”会停止请求并保留已出现的结果。部分书源失败不影响其他书源的结果。

生产构建与本地预览：

```sh
npm run build
npm start
```

打开 <http://127.0.0.1:8787>，由同一服务提供构建后的网页与 API。PWA 离线资源仅在生产构建中启用；首次加载及新书下载需要联网。添加到主屏幕和持久存储授权取决于浏览器支持。

## 已有功能

- 可选账号注册、登录、密码修改与离线恢复码；书架、整理状态、笔记、位置与原文件按账号同步。
- 三列书架、置顶、分组、在读 / 待读 / 读完和批量整理。
- 多书源渐进搜索、文学、开放教材、完结书单与作者作品页。
- 书架追更角标、可选 Web Push、换源保留进度、下载管理与登录后的云端准备章节。
- 沉浸阅读、滑动 / 覆盖 / 上下滚动、背景与夜间模式、字体、字号、行距、独立段距、页边距。
- 左侧目录、每章阅读与缓存状态、按当前排版估算全书页数、进度条跳转、后续 10 章预读与手动章节缓存。
- 阅读页底部显示当前页/总页数与时间；浏览器可读取电量时显示电量，翻页时自动收起控制栏。
- 书签、正文长按段落笔记、已缓存正文搜索；PDF 页书签、笔记与本地文字搜索。
- EPUB / PDF 整本下载，EPUB / PDF / TXT 导入；EPUB 默认文字续读，并提供原版插图、层级标题与脚注入口。
- 系统语音听书、设备音色、语速与试听，15 / 30 / 60 分钟或本章结束停止。
- 书源开关、阅读备份导出与恢复、缓存清理、服务器地址与访问码配置（可选择在此设备记住）。

## 当前边界

**听书。** Web 版使用浏览器的系统语音，不包含 iOS 的 Melo / Kokoro 原生离线 AI 引擎。音色与离线能力由设备、系统和浏览器决定；部分系统音色需要联网。移动浏览器可能在锁屏或后台暂停播放，不能承诺原生 App 一样的持续后台听书。安卓原生推理和后台音频属于后续适配内容。

**电子书。** EPUB 默认文字阅读，恢复跨设备位置及指定章节；主动选择「原版」后按书脊显示安全处理的本地页面，保留插图、CSS、标题和脚注；禁用作者脚本、表单与外网资源，特殊版式可能与出版者阅读器不同。文字模式继续重新排版、听书和标注，原版滚动位置不覆盖云端文字锚点。TXT 按章节标题或长度拆分。PDF 使用 PDF.js 显示原始页面，支持页笔记与本地文字搜索；canvas 暂无正文选择 text layer，不提供 OCR 或 PDF 听书。加密、DRM 或无可提取文字的 EPUB 不支持文字模式。

**后台与通知。** 普通页面挂起或关闭后不能保证下载。登录后可选「云端准备」，由服务端继续准备选中章节；返回前台再逐章保存到本机，「云端完成」不等于本机离线可读。Web Push 需 HTTPS、登录、主动授权和服务端 VAPID 配置；iPhone 需 iOS 16.4+ 添加到主屏幕运行。通知不会使网页长期保活，默认不含书名。见[平台工作流](../docs/reading-workflows.md)。

服务器到部分海外书源的大文件传输存在连接重置，当前不继续排查该链路；这不影响本地文件导入的功能说明。

**存储与备份。** 书架、设置、进度、笔记、正文缓存和导入文件保存在当前账号的 IndexedDB；离线网页资源由 Service Worker 缓存，EPUB 原版滚动位置独立本地保存。未登录数据仅本地保留，登录同一服务器与账号后才同步书架资料和原文件。清除站点数据、隐私浏览或空间回收可能丢失尚未上传的数据。导出备份含书架、整理状态、笔记、进度与设置，**不含原文件及正文缓存**；恢复后从同账号云端重新下载，或重新导入原件。

**书源。** 浏览器通过清读服务查询已登记的书源，规则由服务端维护。“检查书源配置”只做 JSON 格式与必要字段校验，不会把任意网址导入成可用书源，也不会绕过跨域、登录、验证码或 DRM。原站变更、限流和网络问题可能使书源失效。

**服务器与安卓。** Android 使用 KeyStore 加密保存登录、前台服务下载和 WorkManager 本地追更。原生壳不注册 PWA Worker，也不使用浏览器 Web Push。公开 CI 使用临时调试签名，尚无安卓真机验证。见 [Android 说明](android/README.md)。
