# 清读 Web

面向手机浏览器的清读阅读器，桌面也可使用。React + TypeScript 前端与 Node 书源服务放在同一目录；iOS 原生版继续独立维护。

服务端可自行部署；个人数据通过可选用户名与密码账号同步。源码不预设作者服务器，配置见 [部署说明](deploy/README.md) 和 [云同步](../docs/cloud-sync.md)。

## 本地运行

需要 Node.js 24 与 npm（使用内置 SQLite）。在本目录执行：

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173>。该命令同时启动网页与书源服务，Vite 将 `/api` 请求转给 `127.0.0.1:8787`。终端保持运行；按 `Ctrl+C` 停止。开发模式默认只允许这台电脑访问。

初始书架包含明确标记为“本地公版”的《桃花源记》，可直接体验阅读。联网搜书需要书源服务与原书库可访问。搜索结果分批出现；搜索期间点击“取消”会停止请求并保留已出现的结果。部分书源失败不影响其他书源的结果。

生产构建与本地预览：

```sh
npm run build
npm start
```

打开 <http://127.0.0.1:8787>，由同一服务提供构建后的网页与 API。PWA 离线资源仅在生产构建中启用；首次加载及新书下载需要联网。添加到主屏幕和持久存储授权取决于浏览器支持。

## 已有功能

- 可选账号注册与登录、书架、阅读位置与导入原文件跨端同步，账号分别存储；主动合并未登录书架。
- 三列书架、最近阅读、排序、书籍管理与阅读进度恢复。
- 多书源渐进搜索、按书源筛选、失败原因、真实书单与分类。
- 沉浸阅读、滑动 / 覆盖 / 上下滚动、背景与夜间模式、字体、字号、行距、独立段距、页边距。
- 左侧目录、每章阅读与缓存状态、全书估算进度及拖动跳转、后续章节预读、手动章节缓存。
- EPUB / PDF 整本下载，导入 EPUB / PDF / TXT，本地离线阅读。
- 系统语音听书、设备音色选择、语速调整与试听。
- 书源开关、阅读备份导出与恢复、缓存清理、服务器地址与访问码配置（可选择在此设备记住）。

## 当前边界

**听书。** Web 版使用浏览器的系统语音，不包含 iOS 的 Melo / Kokoro 原生离线 AI 引擎。音色与离线能力由设备、系统和浏览器决定；部分系统音色需要联网。移动浏览器可能在锁屏或后台暂停播放，不能承诺原生 App 一样的持续后台听书。安卓原生推理和后台音频属于后续适配内容。

**电子书。** EPUB 导入按书脊顺序抽取文本后重新排版，目前不还原原书图片、复杂版式和脚注跳转。TXT 按章节标题或长度拆分。PDF 使用 PDF.js 显示原始页与图表，独立按页记录位置；没有把 PDF 转成小说式纯文本。加密、DRM 或图片型 EPUB 没有正文时会报错。

服务器到部分海外书源的大文件传输存在连接重置，当前不继续排查该链路；这不影响本地文件导入的功能说明。

**存储与备份。** 书架、设置、进度、正文缓存和导入文件保存在当前浏览器的 IndexedDB；离线网页资源另由 Service Worker 缓存。未登录的数据只保存在本机。登录同一服务器的同一账号后，书架和当前位置自动同步；每个账号使用独立的本地数据库。EPUB/PDF/TXT 原文件自动上传到当前账号，章节缓存不上传。清除站点数据、隐私浏览或浏览器空间回收可能导致本地内容丢失。备份只包含书架、进度和设置，**不包含 EPUB / PDF / TXT 原文件及正文缓存**；恢复后需重新下载或导入原文件。请保留重要电子书原件。

**书源。** 浏览器通过清读服务查询已登记的书源，规则由服务端维护。“检查书源配置”只做 JSON 格式与必要字段校验，不会把任意网址导入成可用书源，也不会绕过跨域、登录、验证码或 DRM。原站变更、限流和网络问题可能使书源失效。

**服务器与安卓。** Android 0.7.0 / code 4 共用账号同步逻辑，记住登录时使用 Android KeyStore 加密保存令牌。公开 CI 使用临时调试签名，尚未在安卓真机运行。见 [Android 说明](android/README.md)。
