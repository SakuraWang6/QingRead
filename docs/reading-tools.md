# 书架、笔记与电子书

[文档导航](README.md) · [云同步](cloud-sync.md) · [下载与通知](reading-workflows.md)

## 正文排版

文字阅读模式统一使用两字首行缩进，书源自带的半角、全角空格或 Tab 不会叠加成更宽的空白，跨页续段也不会再次缩进。调整仅作用于显示，保留原文章节文本、阅读位置及笔记定位。字体或字号变化会重新分页，继续定位到同一原文位置。

正文默认使用系统字体，仍可在阅读设置选择宋体或圆体。升级首次读取旧版宋体设置时会切换为系统字体；之后手动选回宋体会保留，不会在后续启动时反复重置。EPUB 原版与 PDF 继续保留各自的原始版面。

## 书架整理

书架保留三列封面，可置顶、分组，并筛选在读、待读和读完。管理模式支持批量操作。整理状态按账号同步，普通阅读进度更新不会清空分组或笔记。

## 书签、笔记与正文搜索

iPhone、Web 和 Android 的文字阅读页支持直接长按正文整段，打开「段落笔记」，无需进入全文选字。桌面可右键段落，或聚焦段落后按 Enter / Shift＋F10。段落页只展示对应章节、书源和段落的个人笔记；阅读菜单的「书签与笔记」保留全书列表及当前位置书签。笔记支持修改、删除和点击返回。

段落锚点保存完整段落的正文 UTF-16 起点和长度，引用文字只保存最多 500 个 UTF-16 单元的快照，不截断字符。较长段落仍按完整范围定位；历史精确选字笔记继续保留原范围，显示在重叠的段落中。

「正文搜索」只读取当前设备已缓存或已导入的正文，最多返回 100 个匹配，不为搜索联网抓取未缓存章，不上传整章文本或建立云端全文索引。换源后保留旧标注的来源；同名章节可以辅助定位，但不会把旧字符偏移直接套用到新版本。

每本最多保存 256 条标注，笔记最多 1000 个 UTF-16 单元。书签笔记和阅读位置按账号私有保存和同步；未登录时仅本地保存，不提供公共评论区。删除通过同步标记传播，旧离线设备不会自动恢复。

## EPUB：原版与文字

EPUB 默认使用文字模式，恢复跨设备同步的文字位置及指定章节，继续使用清读排版、听书和笔记。在阅读菜单主动选择「原版」，按书脊查看本地页面、插图、CSS 排版、标题层级和脚注；支持多级目录与返回脚注前位置。工具栏「文字」可回到文字阅读。

原版使用安全解包资源：拒绝越界路径、符号链接和过大归档，禁用作者脚本、表单与外网请求；Web 撤销不用的 Blob URL，iPhone 限制 WKWebView 到本书本地目录。既有导入会按原 EPUB 重新生成原版缓存，不改原字节、文件哈希或文字模式的 UTF-16 锚点。

原版的章节及物理滚动位置只保存在当前设备、当前账号，文字模式位置继续跨端同步。外链资源不会加载，特殊版式不保证与出版者指定阅读器一致。DRM、损坏或没有可提取文字的导入仍不在当前文字模式支持范围。

## PDF：页书签与本地搜索

PDF 保留原始页面、图片和图表，通过工具栏一个入口管理页书签、笔记与正文搜索。搜索用本机 PDF.js `getTextContent` 或 PDFKit 文字提取，不请求 OCR 服务。

- iPhone：长按 PDFKit 正文选择文字，再打开笔记入口引用；搜索结果按页跳转并尝试高亮。
- Web / Android：PDF 使用 canvas，支持页书签、页笔记与搜索结果引用，点击结果跳到所在页，尚无正文 text layer 选择或高亮。

PDF 标注统一使用 `pdf-page-<从 0 起的页码>`；页内偏移基于规范化空白后的 UTF-16 文本。两个解析器提取文字的顺序或分段可能不同，因此跨端以原始页码为可靠定位，引用文字辅助核对。图片型 PDF 无可搜索文字，暂不支持 OCR 或 PDF 听书。

## 听书定时

文字阅读的听书面板可选择 15 / 30 / 60 分钟或本章结束停止。iPhone 支持系统音色与可选 Melo / Kokoro 离线 AI；Web / Android 使用系统 Web Speech，音色、后台及离线能力由设备决定。定时受运行环境调度影响，不以浏览器后台定时器承诺精确执行。详见[离线语音](offline-voice.md)。

## 发现与作者

推荐、分类增加经典文学、开放教材和完结作品入口，书籍详情可点作者查找同作者作品。结果来自来源公开目录与实际作者字段，未确认作者的作品不会当作同作者推荐；「完结」书单不表示每个来源的正文已逐章核验完整。它们不是个性化推荐或全网排行。
