# 追更、换源与下载

[文档导航](README.md) · [账号同步](cloud-sync.md)

各端共用章节匹配、进度保护和下载管理规则，后台执行方式随平台不同。本机缓存与下载任务按设备、账号独立保存，书源选择及阅读位置随书架同步。

## 追更与通知

书架刷新检查已收藏的联网章节书，有新增时显示「更新 N 章」。iPhone 支持下拉检查；打开书架、回到前台和读到目录末章时也会尝试检查。已有目录作为基线；首次没有目录时只建基线，不把整本算作新增。目录重排或旧末章无法唯一匹配时不猜测新增数量，失败保留旧目录与正文。

前台自动检查每本至少间隔 15 分钟，手动检查至少间隔 60 秒，失败也冷却。系统通知默认关闭，在设置中主动开启：

| 平台 | 通知方式 | 边界 |
| --- | --- | --- |
| iPhone 原生 | 前台及系统允许的后台刷新检查后，发出本地通知 | Personal Team 不具备原生 APNs 能力；后台刷新时机由 iOS 决定，不能保证准点 |
| Web / PWA | 自建服务用免费 VAPID Web Push 检查选中的云书架并提醒 | 需 HTTPS、登录、浏览器授权及服务端配置；iPhone 需 iOS 16.4+ 主屏幕 PWA |
| Android | WorkManager 联网且电量不低时尝试检查，使用本地通知 | 需主动授权；受系统与厂商省电策略影响，强行停止后不保证执行；尚无真机验证 |
| HarmonyOS | API 23+ 使用 WorkScheduler 定期检查并发本地通知，旧系统保留前台检查 | 默认关闭，需主动授权；至少两小时间隔，由系统调度，强行停止后不保证执行；无需 AGC，不是远程 Push |

Web Push 默认仅显示「清读／书架有新章节，打开查看」，不传书名或图书地址。每账号最多选择 20 本、5 个订阅设备；全服务器每分钟至多检查一个目录、同书至少间隔一小时、每账号每小时最多一条合并提醒，失败逐步退避。不扫描未启用用户的全库，不抓取正文。网络无法访问浏览器推送服务时不能送达，配置与接口见 [Web Push](../web/server/PUSH.md)。

鸿蒙本地提醒每轮最多检查三本，串行执行，最多运行 80 秒，每请求限 20 秒；首次只建立基线。通知不含书名与来源地址。检查范围绑定当前账号、服务与来源，退出账号或关闭开关后旧任务失效；访问码只使用用户已选择记住的安全存储值。API 12–22 不启用后台检查，以避免旧网络接口自动重定向时转发访问码。

## 换源

章节书的详情与阅读菜单提供「换源」。候选来自已启用来源的同名书，双方有作者时还需作者匹配；EPUB/PDF/TXT 整本文件不执行章节换源。

先获取新目录，按唯一章节标题或编号匹配，支持常见中文章号；匹配不确定时手动选章。新目录与目标正文成功落盘前保留原书架、位置和缓存，失败或取消不会切换。逻辑书籍 ID 和加入日期不变，章内进度按比例映射，不把旧正文的绝对字符偏移用于新正文。

服务端拒绝旧来源进度覆盖新书源；并发换源需当前修订号。其他设备收到来源变化后使旧目录、正文和下载请求失效，活动阅读器重载新来源。各设备应更新到当前版本；不同版本的正文、排版和页码仍可能不同。

## 下载管理

详情或阅读菜单可选后续 50 / 100 章、当前目录整本、自选范围。已缓存章节计入完成并跳过；重复添加同一活动范围复用任务。下载管理集中暂停、继续、取消和重试，保留最近 20 条结束记录。删除书籍、禁用来源、清缓存或切换账号会停止对应旧请求。

| 平台 | 离开页面后的执行 | 正文何时进入本机缓存 |
| --- | --- | --- |
| iPhone 原生 | 已交给后台 URLSession 的有限章节批次由系统继续传输 | 系统回调恢复应用后校验并保存；新批次衔接受系统调度影响 |
| Web 本机下载 | 页面被挂起或关闭时不能保证继续 | 页面活跃时逐章保存 |
| Web 云端准备 | 登录后选用云端准备，服务器可在标签页关闭后继续 | 返回下载管理，前台逐章验证并保存到当前设备 |
| Android | 用户启动的 `dataSync` 前台服务运行，通知栏显示进度与暂停 | 原生私有暂存；回到应用后核对账号、来源并导入 IndexedDB |
| HarmonyOS | 云端准备完成后，系统 request.agent 传输一个受控的完整结果文件；未登录时沿用前台下载 | 原生私有暂存；返回前台按账号、来源、文件哈希与章节内容校验，全部写入后计入本机缓存 |

iPhone 后台章节下载需要配置可用服务；每批最多 10 章、5 MiB，服务器仍校验书源与目录。系统可延迟或取消传输，用户强制退出不能承诺继续。前台旧队列与后台批次用同一任务身份去重，暂停与迟到回调不能回填已取消任务。

云端准备全实例单并发、章间至少 1 秒、每章最多三次尝试，连续失败安全暂停；每账号最多 2 个活动任务、100 MiB，全局最多 10 个、512 MiB，默认 7 天过期。账号退出使原会话任务暂停；删除或换源会清除旧来源任务。云端「已准备」与本机「已缓存」分别计数，云端完成不代表手机已离线保存。见[云端准备接口](../web/server/OFFLINE-JOBS.md)。

Android 系统限制前台服务启动及累计后台运行时长，不做无限保活；详细限制和验证边界见 [Android](../web/android/README.md)。普通网页不能靠推送或 Service Worker 保持长时间下载。

鸿蒙系统传输最多两个活动任务、20 条保留记录，单文件最多 128 MiB，只接收当前服务固定的云任务结果地址。暂停后继续会新建任务完整重下，不拼接半份 NDJSON。账号、服务或来源变化会使旧任务和迟到回调失效；系统下载完成与本机缓存完成分别显示。系统可能延迟、终止任务，不保证强制退出后继续运行。

不同设备不自动复制本机下载队列。整本 EPUB/PDF/TXT 的原文件下载和账号文件同步保持独立；正文缓存和云端准备临时文件不作为书架同步内容。
