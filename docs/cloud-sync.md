# 账号与跨端同步

[文档导航](README.md) · [服务器部署](../web/deploy/README.md)

清读使用自建服务器的用户名和密码自助注册，不依赖邮箱、短信或付费身份服务。用户名 2–32 个字符，密码 10–128 个字符。账号页面提供修改密码、生成恢复码和凭恢复码重设密码；不提供邮箱验证或自助删除账号。

## 开始使用

1. 配置同一个 HTTPS 服务器：Web/Android 的「设置 → 服务器连接」，iPhone 的「设置 → 账号与同步」。
2. 注册自己的账号，在其他设备登录同一账号；朋友单独注册账号。
3. 如需保留未登录时的已有书架，主动点「合并本机未登录书架」。登录和切换账号不会自动合并。
4. 已导入的 EPUB/PDF/TXT 在登录账号后自动上传。另一设备登录后点击书籍，按需下载原文件并恢复位置；已下载的书仍可离线读。
5. 有修改时延迟约 2.5 秒尝试同步，前台每 20 秒检查一次；重新联网或回到 App 也会尝试。可手动点「立即同步」。iOS 后台调度和断网时不能保证立即同步。

## 同步范围

同步书籍资料、加入书架状态、置顶、分组、在读 / 待读 / 读完状态、书签笔记，以及当前章/页、章内比例和正文 UTF-16 字符偏移。不同字号、排版或设备会重新排版，因此页面编号可能不同；相同书籍和版本的文本位置才可准确匹配。小说页码按当前排版和已有正文估算，不作为跨端同步锚点；PDF 使用原始页码。

章节换源沿用原逻辑书籍 ID，来源元数据和新位置一起同步。服务端不允许旧来源进度把书源改回去，并用修订号保护并发换源；客户端收到来源变化会清理旧目录和正文。正文锚点不计入原生排版的标题前缀。追更角标、本机下载任务和章节缓存按设备与当前账号独立保留，不在书架同步范围内；可选云端准备任务由本人账号单独管理。见[追更、换源与下载](reading-workflows.md)。

书签笔记按条目 ID 与修改时间合并，删除保留标记，旧设备不会恢复已删笔记。标注记录原来源、章节与 UTF-16 位置；换源后不把旧字符偏移直接用于不同正文。PDF 标注采用 `pdf-page-<从 0 起的页码>`，两端都能按页打开；PDF.js 与 PDFKit 的文字提取可能不同，页内引用位置不保证逐字相同。EPUB 原版的物理滚动位置仅保存在当前设备，文字模式的位置继续跨端同步。见[书签与电子书](reading-tools.md)。

同步书架上已导入的 EPUB/PDF/TXT 原文件（也包括已经下载的整本书）。每个账号单独存文件，不跨账号共用下载权限；知道其他人的文件哈希或书籍 ID 仍不能读取。未登录文件只有在主动合并到账号书架后才上传。

原文件采用 SHA-256 验证完整性；文件传输和书架/进度同步独立，上传时仍可正常阅读和保存位置。另一端按需下载、导入正文与封面并保留原进度。不上传语音模型与网站章节缓存。服务器没有原文件或正在上传时，另一设备需等待上传完成，不能凭书架记录凭空生成文件。

默认单本不超过 250 MiB，每账号 2 GiB、所有账号合计 10 GiB，始终预留至少 5 GiB 磁盘。上传仅一个并行任务，下载最多两个，整个文件不缓冲到 Node 内存。空间或网络不足时本机原文件保留，可在账号页面重试。删除书架书籍会移除对应云文件；同一账号的其他书籍仍引用该文件时保留。读书进度、数据库与文件目录需一并备份。

每个账号有独立本地存储；退出后返回未登录书架，其他账号不会自动看到前一个账号数据。本地离线数据仍保留在设备上，设备本身应设置锁屏。浏览器清除站点数据仍可能丢失尚未上传的操作和文件，请保留原文件与备份。

## 冲突与重试

客户端持久化待上传操作，使用随机操作 ID 重试而不重复应用。服务端按账号分配修订号、分页返回变更；移除保留墓碑，旧离线设备不能把已删书籍自动加回来。明确重新加入时需要已见过删除修订号。阅读位置采用较新时间戳，允许主动往回读；设备时钟相差过大仍可能影响判断，服务端会限制未来时间戳。进度更新不会清空书架整理与笔记；这些资料有独立修改时间。

## 密码与恢复码

修改密码需要当前密码。修改成功后撤销旧会话，只保留本次返回的新会话，其他设备需重新登录。账号数据不会因此删除。

登录后输入当前密码可生成或轮换离线恢复码。恢复码只显示一次，服务器只保存哈希；新码替换旧码。忘记密码时用用户名、恢复码和新密码恢复，成功后恢复码被消费、旧会话失效，应重新生成一份。未提前保存恢复码时，没有邮箱或短信兜底找回通道。

## 身份与运维

服务端 SQLite 只存带盐 scrypt 密码哈希和随机会话的哈希，个人数据由会话对应用户隔离；客户端不能指定数据归属。会话有效 30 天，退出尝试撤销；离线退出会先删除本机凭据，服务端旧会话最终到期。

iPhone 使用 Keychain 保存令牌；Android 记住登录时使用 Android KeyStore 加密；Web 默认仅当前会话保存，主动勾选后才持久保存。密码不写入客户端存储。会话绑定服务器地址，重定向被拒绝。

生产目录 `app-data` 必须可写、独立持久化并备份；不得打进 Docker 镜像或提交 Git。详见 [部署说明](../web/deploy/README.md)。开放书源的免访问码模式不会取消个人同步认证。当前适合小规模自用和朋友共享，默认最多 100 个注册账号，不提供公众平台级的运营能力。
