# 账号与跨端同步

0.6 使用自建服务器的用户名和密码自助注册，不依赖邮箱、短信或付费身份服务。用户名 2–32 个字符，密码 10–128 个字符。当前没有邮箱验证、密码找回、密码修改或自行删除账号的界面；忘记密码需联系服务器维护者。请保存自己的密码。

## 开始使用

1. 配置同一个 HTTPS 服务器：Web/Android 的「设置 → 服务器连接」，iPhone 的「设置 → 账号与同步」。
2. 注册自己的账号，在其他设备登录同一账号；朋友单独注册账号。
3. 如需保留未登录时的已有书架，主动点「合并本机未登录书架」。登录和切换账号不会自动合并。
4. 有修改时延迟约 2.5 秒尝试同步，前台每 20 秒检查一次；重新联网或回到 App 也会尝试。可手动点「立即同步」。iOS 后台调度和断网时不能保证立即同步。

## 同步范围

同步书籍资料、加入书架状态、当前章/页、章内比例和正文 UTF-16 字符偏移。不同字号、排版或设备会重新排版，因此页面编号可能不同；相同书籍和版本的文本位置才可准确匹配。章数占比是估计进度，PDF 按原始页码。

不上传 EPUB/PDF/TXT 原文件、正文、封面文件、语音模型或缓存。其他设备重新下载或导入同一份文件；SHA-256 匹配云端书籍，保留书籍 ID 与进度。文件字节不同会拒绝绑定，避免错误匹配版本。历史本地文件在主动合并时补充哈希。

每个账号有独立本地存储；退出后返回未登录书架，其他账号不会自动看到前一个账号数据。本地离线数据仍保留在设备上，设备本身应设置锁屏。浏览器清除站点数据仍可能丢失尚未上传的操作和文件，请保留原文件与备份。

## 冲突与重试

客户端持久化待上传操作，使用随机操作 ID 重试而不重复应用。服务端按账号分配修订号、分页返回变更；移除保留墓碑，旧离线设备不能把已删书籍自动加回来。明确重新加入时需要已见过删除修订号。阅读位置采用较新时间戳，允许主动往回读；设备时钟相差过大仍可能影响判断，服务端会限制未来时间戳。

## 身份与运维

服务端 SQLite 只存带盐 scrypt 密码哈希和随机会话的哈希，个人数据由会话对应用户隔离；客户端不能指定数据归属。会话有效 30 天，退出尝试撤销；离线退出会先删除本机凭据，服务端旧会话最终到期。

iPhone 使用 Keychain 保存令牌；Android 记住登录时使用 Android KeyStore 加密；Web 默认仅当前会话保存，主动勾选后才持久保存。密码不写入客户端存储。会话绑定服务器地址，重定向被拒绝。

生产目录 `app-data` 必须可写、独立持久化并备份；不得打进 Docker 镜像或提交 Git。详见 [部署说明](../web/deploy/README.md)。开放书源的免访问码模式不会取消个人同步认证。当前适合小规模自用和朋友共享，默认最多 100 个注册账号，不提供公众平台级的运营能力。
