# 清读设计

日期：2026-10-20。

## 产品目标

用户希望在 iPhone 上输入书名，直接找到不同来源的小说，收藏并阅读，不想逐本寻找网址，不接受广告和会员门槛。选择原生 SwiftUI 客户端，自用安装；服务器和商店分发不是首版前提。

首版优先打通真实阅读链路，内置经核实的网络小说和经典文本来源，另提供网站规则导入。已针对用户指定的两本网络小说验证搜索、目录和首章；更广泛的覆盖率、旧阅读书源兼容性和复杂网页解析仍需继续验证。

## 模块边界

`ReadingCore` 是没有 SwiftUI 和持久化依赖的 Swift 包：来源声明、网络传输、搜索、目录与正文解析由它负责。每个来源把自己的结果映射到统一的 Book / Chapter / ChapterContent，界面不包含网站 CSS 选择器。

App 层在主线程管理可观察状态；搜索任务可取消，旧请求不得覆盖新查询。界面负责加载、空结果、部分失败与重试，而不把网络异常解释成没有这本书。

书架、阅读设置和章节内容分别持久化。章节缓存按书籍和章节稳定标识分开存放，阅读位置按文字锚点保存。清除正文缓存不清除书架和阅读进度。删除书籍只能影响该书的数据。

## 搜索与来源

请求从 iPhone 直接发往来源，不经开发者服务器转存。查询词由引擎编码。多来源并发查询，单个来源失败不使整次搜索失败；同书各来源保留可识别的出处。

内置来源用于实际验证基础能力，不代表覆盖全部网络小说。导入规则采用简单 CSS 声明；首版不运行第三方 JavaScript，也不声称兼容 Legado 的完整规则语言。需要执行 JavaScript 或登录的来源应单独设计，不隐式塞进解析器。

## 视觉与交互（0.3 更新）

界面使用中性暖白、橙红强调和系统字体，固定三列封面书架。参考番茄小说的书架密度和阅读菜单行为，没有复制其素材。推荐和分类取自来源公开页面，解析位于 ReadingCore/DiscoveryService，界面只处理书目和加载状态；停用来源即停止请求。

ReaderSettings 保存并迁移旧版设置。ReaderDocument 用统一 UTF-16 文档描述章节，ReaderCanvas 的 TextKit 连续容器决定实际页界，同一锚点用于翻页、滚动、位置持久化和语音定位。中央点击控制菜单显示，两侧边缘向内滑动返回，正文中央滑动用于翻页。

ReaderSpeechController 管理系统中文朗读、音频会话、锁屏控制和播放意图。切章先停止旧语音；加载任务只能沿用仍然有效的续播意图，用户停止后不得在加载完成时重新播放。后台保留听书，退出阅读器停止。

ReaderBookProgress 在章节等权的前提下映射整书百分比与章节内部 UTF-16 位置。左侧目录只展示实际访问过的各章最大进度，不根据当前章推断前文全部读完。AppStore 保留单本书当前位置和独立逐章进度；前台与预缓存共用请求，后续 10 章依次缓存。目录写回受全局与每本书缓存世代保护，清缓存或移除后旧响应不能回填。

BookCoverCache 独立管理内存与磁盘缩略图，最多同时三个远程封面链路；必要时通过 ReadingCore 获取同一作品详情页的封面元数据。缺图时使用书名排版，不从其他作品猜图。图片缓存位于 Caches，可由系统清理，不和正文缓存混淆。

ReaderSpeechCursor 统一管理可替换系统 utterance 的 UTF-16 起点，调速或换音色不退回段落开头。OfflineSpeechEngine 将 Melo 模型加载、短句生成和销毁约束到后台队列，本地播放器负责速率、暂停与锁屏音频；只预生成下一句，并用世代标识丢弃停止前的结果。AIModelManager 只在用户点击后下载固定模型，逐文件校验并整批发布；模型合成没有服务器环节，下载中断不产生可选用的半份声库。组件版本和完整依赖声明见 offline-voice.md。

不引入广告 SDK、内购或账户系统。推荐是来源发布的书目，不伪称个性化模型或全网排行。无网络时仍可继续阅读缓存和本地样例。

## 安装和开发

Swift 包测试可以用 Command Line Tools 执行；原生 UI 构建需要完整 Xcode 与 iOS SDK。Xcode 工程由仓库内 Python 脚本生成，不要求安装额外项目生成器。

付费 Apple Developer 会员不是写代码或模拟器运行的前提。签名只在安装真机时配置，仓库不保存团队 ID、证书与密钥。
