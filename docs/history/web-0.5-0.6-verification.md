# 清读 Web 0.5 本地验收

日期：2026-10-20。预览为本机生产构建，不代表已部署服务器。

- 38 项离线自动测试通过；4 项上游联网用例默认跳过。iOS ReadingCore 32 项测试通过。
- 真实来源检查：两本用户常看小说均取得目录及首章；Gutenberg / Standard Ebooks 整本 EPUB、OpenStax PDF 头部与经典文学来源已检查。书源可用性会随原站变化。
