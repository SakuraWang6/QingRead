# 书源格式 v1

本格式是清读首版的声明式配置，不是 Legado 完整兼容层。导入一次来源后，读者输入书名搜索即可，不需要逐本粘贴网址。

## 内置来源

共 10 个：5 个网络小说网站、2 个经典文本来源，以及 3 个整本书库。

- **笔趣阁 · biequgei**：通过网站真实 GET 搜索接口查找小说，已验证用户指定的两本书；解析完整目录区域，避免把顶部倒序更新列表误当正序目录。
- **我书阁**：真实 GET 站内搜索，作为另一小说来源。已验证《超神机械师》，《这游戏也太真实了》本次未命中。不能据此认为该书不存在于所有来源。
- **沧海书阁**：通过 `/search.html?q=...` 搜索，详情页直接包含目录，返回真实封面地址。部分书籍不完整：本轮《这游戏也太真实了》仅返回 100 个目录项，不将其标为全本。
- **笔趣阁 · biquge.tw**：通过 `/search/?searchkey=...` 搜索，与 biequgei 是独立网站。跟随详情页的“章节目录”链接解析完整目录，返回搜索结果中的真实封面地址。某些旧章节标题存在站点原有乱码。
- **飘天文学**：使用 GBK 搜索词调用公开 GET 搜索接口。精确书名可能直接重定向到书籍页，模糊搜索返回多结果表格，两种情况均提取网站给出的目录链接。正文是 HTML `body` 中的直系文本，清理周围导航与脚本后分段；不依赖执行 JavaScript。精确结果有真实封面，列表结果没有封面时留空。
- **古典小说精选**：本机匹配预置书名与作者，按需从 `luoxuhai/chinese-novel` 获取真实目录与章节。目前包括《三国演义》《西游记》《红楼梦》。搜索不需要联网，阅读尚未缓存的章节需要联网。
- **中文维基文库**：通过 MediaWiki Action API 的 `intitle:"书名"` 检索作品标题，查询先转繁体，本地匹配再统一繁简。排除目录子页、消歧义页以及标题明显为判决书、裁定书等法律文书的结果；不再用正文中偶然提到小说的文书充当搜书结果。该文库更适合按作品名搜经典，不作为现代网文的全文搜索引擎。目录按书页子页面提取，短文按单章处理。

来源的名称和主页保存在每个结果中，可以打开原始网页核对。关闭某来源只影响后续搜索，不主动删除缓存。

## 导入 JSON

在“书源”中选择文件，或粘贴 JSON。支持单个来源对象、来源数组，或者 `{"sources": [...]}`。`id` 必须唯一且不能覆盖内置 ID。一次最多 100 个来源。

HTML 站点的格式如下。`example.com` 是说明占位符，不是可用小说来源；需要换成目标站点实际地址和选择器。

```json
{
  "id": "my-site",
  "name": "我的来源",
  "summary": "根据目标站点结构填写的规则",
  "homeURL": "https://example.com/",
  "kind": "html",
  "html": {
    "searchURL": "/search?keyword={query}",
    "encoding": "utf8",
    "resultSelector": ".book-item",
    "titleSelector": ".title",
    "linkSelector": "a.title",
    "authorSelector": ".author",
    "summarySelector": ".summary",
    "catalogLinkSelector": "a.catalog",
    "chapterSelector": ".chapters a",
    "contentSelector": "#chapter-content",
    "removeSelectors": [".ads", ".navigation"]
  }
}
```

| 字段 | 含义 |
| --- | --- |
| `searchURL` | 绝对地址或相对主页路径，必须有 `{query}` 占位符；首版为 GET 请求 |
| `encoding` | `utf8`（默认）、`gb18030` 或 `gbk`，用于搜索词编码及网页无有效声明时的解码后备值。网页的有效 `meta charset` 声明优先，支持 UTF-8、GBK/GB2312/GB18030、Big5；未知声明或按声明解码失败时回退到配置 |
| `resultSelector` | 搜索结果中每本书的容器 |
| `titleSelector` | 在每个结果容器内提取书名 |
| `linkSelector` | 在结果容器内选择书籍链接，提取 `href` |
| `authorSelector` / `summarySelector` | 可选作者、简介选择器 |
| `coverSelector` | 可选封面 `img` 选择器，解析 `data-src` 或 `src` 成为 `Book.coverURL`。客户端可按需展示；没有封面时留空 |
| `catalogLinkSelector` | 可选；书籍页另有目录链接时填写，否则直接在书籍页提取目录 |
| `chapterSelector` | 目录中的章节链接选择器，按页面出现顺序读取 |
| `contentSelector` | 章节正文容器 |
| `removeSelectors` | 从正文移除的节点，默认空数组；脚本和样式始终清理 |

HTTP 来源受 iOS App Transport Security 限制。首版工程使用系统默认安全网络策略，实际使用请提供 HTTPS 来源。不会为导入规则全局关闭系统网络安全检查。

## 实际来源验证（2026-10-20）

三个新增网站都使用网站自己的公开搜索表单，不依赖外部搜索引擎，也没有内置书名到结果地址的对应表。使用清读的 HTTP 客户端实际验证“搜索 → 详情/目录 → 第一章”，仅记录条数和正文段数，不将整章文本作为仓库 fixture。离线回归测试使用同样页面结构的最小人工样本。

| 来源 | 搜索接口与目录入口 | 解析方式与已知限制 |
| --- | --- | --- |
| [沧海书阁](https://www.canghaishuge.com/) | `/search.html?q={query}`；`#catalog .list a` | UTF-8；《超神机械师》详情为 `/chaoshenjixieshi/`，第一章为 `1.html`。目录可能不全 |
| [biquge.tw](https://www.biquge.tw/) | `/search/?searchkey={query}`；详情的 `a.chapterlist` | UTF-8；目录 `.booklist > ul > li > a`，正文 `#chaptercontent`；每本书的路径来自实际搜索结果 |
| [飘天文学](https://www.piaotia.com/) | `/modules/article/search.php?searchkey={query}`，搜索词 GBK；精确结果的“点击阅读”或列表第二列是目录链接 | GB2312/GB18030；目录 `.centent li a`；正文取 `body` 直系文本和 `br`，移除 `body > :not(br)`，避免带入导航 |

实际端到端记录（均为来源当时返回，不能据此保证书目完整或后续一直可用）：

| --- | --- | --- | --- |
| 沧海书阁 / 超神机械师 | 2 本，精确命中 | 1121 项 | 57 段 |
| biquge.tw / 超神机械师 | 20 本，精确命中 | 1517 项 | 48 段 |
| 飘天文学 / 超神机械师 | 1 本，精确命中后跳转详情 | 1468 项 | 48 段 |
| 中文维基文库 / 三国演义 | 2 个标题相关结果 | 精确作品 123 项 | 可读取 |
| 中文维基文库 / 桃花源记 | 1 个结果 | 1 项短文 | 可读取 |

排除的候选也经过实际探测：台灣小說網正文容器只有空占位与“章节报错”，文林社首章 HTTP 403，就读书的分页在复核中持续超时或 HTTP 502。三者均不作为内置可用来源。未为这些失败站点保留额外分页配置字段。

普通测试：`swift test`。显式联网复核：`QINGREAD_LIVE_SOURCES=1 swift test --filter liveSourcePipelines`，会对三个新增源以及维基文库的《三国演义》《桃花源记》走真实读取链路，并核对维基文库不会为《超神机械师》返回无关文书。联网测试需要网络，不作为默认离线 CI 的依赖；网站后续改版或下线需更新配置。


## 整本书库（0.4）

直接加入同一搜书流程，不要求用户找书的网址。下载在详情页显示进度，可取消；完成后加入书架并离线保存。EPUB/TXT 分为本地章节沿用阅读器和听书；PDF 使用 PDFKit 保留版面与图表，记录所在页，暂不提供 PDF 听书。EPUB 当前提取正文，未复现原始 CSS、内嵌插图和复杂脚注，数学/图表密集书籍应优先选 PDF。

| 官方书库 | 范围与格式 | 2026-10-20 实测 |
|---|---|---|
| [Project Gutenberg](https://www.gutenberg.org/) | 中外经典，EPUB；搜索词转换为繁体以匹配中文书目 | 红楼梦 → 1 本《紅樓夢》，1,228,855 bytes，解析 12 节（该来源单册） |
| [Standard Ebooks](https://standardebooks.org/) | 精校英文文学，EPUB；跟随出版者下载中间页的 meta refresh | Tolstoy → 12 本，首本 The Power of Darkness 下载 686,454 bytes，解析 11 节 |
| [OpenStax](https://openstax.org/subjects) | 主要为英文开放大学教材，PDF；支持统计、微积分、物理、经济等中文关键词映射 | 统计 → 5 本相关教材；首本 PDF 下载 106,819,604 bytes，文件头有效 |

EPUB/ZIP 读取检查归档条目数、展开大小、读取大小、资源路径和符号链接；只在内存提取正文资源，不把归档路径写入文件系统。单本导入上限 250 MB，TXT 上限 20 MB；损坏、加密或纯图片 EPUB 会明确失败。整本文件保存在 ImportedBooks，清理网页章节缓存不会删除已导入文件，移出书架会删除该书本地文件。

## Z-Library 的接入边界

Z-Library 属于整本电子书检索/文件下载一类服务，不能用一个空网页章节规则冒充支持。本轮没有确认可匿名访问且可信的“书名搜索 → 目录 → 首章”接口；只探测历史项目入口时遇到 307 重定向循环，未登录，也未采用搜索引擎里自称“官方”的新镜像。

本轮用户没有可提供的入口，要求优先官方来源；复核候选入口仍无法可靠访问，故暂不内置。现在支持把用户自行取得的 EPUB、PDF、TXT 导入到本地阅读器；这不计为已接通 Z-Library 在线搜索。当前没有新增名为 Z-Library 的空配置，也不执行自动登录、验证码处理或受限文件下载。

## 尚未支持

首版不执行 JavaScript，不支持 XPath、JSONPath、带脚本的 Legado 规则、POST 搜索、自定义 Cookie 登录、验证码自动处理、目录翻页和正文跨页拼接。导入其他软件的复杂书源可能因格式不匹配而失败，需要为本站编写声明式规则。

## 回归检查

修改规则时，至少核实搜索结果、相对链接、目录顺序、正文分段和空内容失败信息。不要只验证能打开首页。真实网站会改版，应把可公开的最小 HTML 样本放进测试 fixtures，避免依赖持续联网的测试。
