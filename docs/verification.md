## 排版回归

0.10 的注释下划线直接修改了 TextKit 正文属性，使已有分页布局失效。页面继续使用先前的字形范围绘制，可能把章末文字叠在章标题上或出现空白。已用同一专用 iPhone 模拟器、同一本地公版《桃花源记》复现，并完成修复前后截图对照。

下划线现在仅在显示层绘制，不修改正文存储；每页绑定其文本容器，绘制前完成布局并裁剪到正文区域。滑动、覆盖、滚动三种模式均检查了批注更新不使布局失效、清除批注后页面像素一致、第二段触点准确、标题与空白不触发、大字号与尺寸变化。原有前后跨章动画、预排版复用、回翻上一页与阅读位置检查仍通过。

Web 修正页边换行生成额外空段的问题；跨章正文未匹配时等待新章，不再使用上一章正文计算分页。实际浏览器中给第二段保存笔记后，四个可见段落的位置、高度和文字均与保存前一致。

## 段落笔记

文字阅读直接长按段落打开个人笔记，跨页段落仍引用整段；iPhone 不再打开整章选字页。桌面支持右键或聚焦段落后 Enter / Shift＋F10。短点、滑动、取消和复制保留各自行为。

旧精确选字笔记保留原范围，旧零长度笔记按所属段落展示；书签不混入段落笔记。同步引用快照仍最多 500、笔记最多 1000 个 UTF-16 单元，完整段落范围可超过快照长度。内存服务实测接受整段范围与旧精确范围，未改变服务端协议或账号隔离。这是个人笔记，不包含公共评论区。
