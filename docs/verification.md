## HarmonyOS 原生能力

固定 `https://localhost/` 资源白名单与 TLS 拒绝策略保持启用，不启动本地服务器，不将 API 或凭据交给资源拦截器。v2 WebMessagePort 仅交给固定来源主文档，随机握手、请求白名单、消息/并发/速率限制与文档世代检查限制原生调用。旧宿主按探测到的能力降级。

在官方 CLT 26.0.0.851 / Hvigor 6.26.8 工具链与 HarmonyOS 7.0.0 模拟器实际验证：

- 系统选择器导入 EPUB、PDF、TXT，分类封面与阅读页面正常；覆盖安装保留书架和位置。
- 安装身份显示 0.12.0（2），电量来自系统；设备存在的离线女声能播放与结束，未安装男声不会列成可用音色。调速在下一短句生效。
- ASSET 固定槽在隔离诊断 App 使用合成值完成写入、读取与清除；未读取真实账号会话。保存失败不降级为明文持久存储。
- 系统 SavePicker 保存 4,277 字节备份后，原字节 SHA-256 一致；再次取消未新增文档，暂存清空。大备份分块主动节流，原生限流未放宽。

隔离诊断 App 使用临时合成账号与一本公版书的首章，实际登记系统下载、进入后台、返回后读到完整 15,996 字节，与独立 HTTPS 参考文件的 SHA-256 一致；确认后清除原生暂存和系统任务。排查中发现有界 Range 请求不适用于动态 NDJSON 接口，已移除该请求，暂停后继续仍完整重下；没有为此改变服务端接口。

成品模拟器显示系统通知授权弹窗，允许后开启与本地任务注册成功，一本公版书的检查范围成功持久保存；验证后关闭临时检查。首次授权等待延长到两分钟，普通请求时限不变，并覆盖延迟 20 秒允许、拒绝与普通请求超时回归。没有将短时注册成功描述为两小时周期送达已验证。

后台下载和本地提醒使用不同系统机制：request.agent 仅传输当前账号已准备的云任务文件，返回前台校验后导入；WorkScheduler 只做有限目录检查。API 23 以下不启用后台检查，通知默认关闭、由用户主动授权。系统长期调度、强制退出与耗电仍需真机观察。细节见[平台工作流](reading-workflows.md)。

系统听书在切后台时暂停，不声明锁屏播放、Melo / Kokoro 或 AGC 远程 Push 能力。未签名模拟器 HAP 不作为朋友可直接安装的发行包。

- Web：完整测试 265 项通过、4 项真实书源检查按既定条件跳过，TypeScript 与两套最终构建通过。覆盖大备份节流、下载两遍校验、账号切换和配置失败重试，手动与自动导入不会重复执行。
- HarmonyOS：`node --test harmony/tests/*.test.mjs` 共 34 项通过，覆盖资源来源、桥接、语音、安全存储、备份、后台传输、追更隔离与预算；官方 SDK 编译独立执行，不以宿主 mock 代替实际编译。

运行时代码提交 `0436412` 的 [Web CI](https://github.com/SakuraWang6/QingRead/actions/runs/39987017100) 与 [Android CI](https://github.com/SakuraWang6/QingRead/actions/runs/39987017132) 已通过。后续模拟器等待修复由 [iPhone 完整检查](https://github.com/SakuraWang6/QingRead/actions/runs/39989260300)验证，执行状态与截图以该记录为准；没有因此替换已验签的运行时安装包。

模拟器 CI 总时限为 30 分钟，记录命令耗时及脱敏、限长错误尾部。一次云端运行在系统首次迁移等待 300 秒后超时，恢复关机又超过 60 秒，尚未进入 App；据此将首次冷启动等待设为 600 秒、关机 120 秒，暖启动与唯一恢复的等待仍为 300 秒。保持同一设备、唯一恢复及全部阅读断言，命令最坏启动预算为 19 分钟，不跳过检查或无限重试。
