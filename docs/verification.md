## 追更、换源与下载

- Web/API 完整测试为 **112 项通过、4 项实时书源测试跳过**，共 16 个测试文件（15 通过、1 跳过）。TypeScript 与根路径、`/qingread/` 两种生产构建通过。
- Swift 新增工作流 XCTest **6 项通过**；既有 Swift Testing **34 项通过**。覆盖章节标题与编号匹配、歧义处理、保守的追更判断、下载范围与断点状态。
- 原生存储自检通过追更标记、缓存跳过、换源失败保留原数据、旧阅读器保护、云端换源缓存失效、暂停持久化、账号隔离、退到后台暂停、下载去重及历史数量上限。既有导入、进度、预取和清缓存期间请求失效自检均通过。
- Web 工作流回归还覆盖下载运行中换源仅在事务落盘后发布来源、限频失败重试、换源取消及写入失败回滚、陈旧计划失效、串行下载、有限重试、移除书籍后停止任务和账号间任务隔离。
- 服务端同源进度只合并阅读位置；旧源进度和陈旧的并发换源会被拒绝并返回权威记录。新源的书籍元数据与章节锚点一并替换，保留逻辑书籍 ID；同源补充原文件身份时仍保留已有文件哈希。同步和云文件相关测试通过。
- 追更标记和下载队列保存在各设备、各账号自己的本地数据中；云端同步书源选择与当前位置，不上传网站章节缓存或下载任务。这里的追更提醒是书架内的新章标记与主动检查，尚不包含系统推送。

使用本地虚构书籍进行移动端浏览器交互验证：自选章节范围加入下载、任务完成、新章角标、取消换源保留原位置、确认换源后保留原章节比例均通过；线上 PWA 更新后原有书架保留，新入口可见。

## 阅读器

- 原生 UIKit 回归覆盖滑动／覆盖 × 向前／向后四条跨章路径，确认先完成页面动画再提交章节变化，复用已准备的 TextKit 布局；0.9.0 复跑均通过，随后普通翻页仍正确。
- 点击正文左侧在本章内回到上一页，仅第一页才回到上一章末页。末页目标在视口尺寸变化时仍能恢复。
- UTF-16 连续分页、字号重排、文字锚点恢复、进度跳转和语音意图回归通过。0.9.0 四条跨章路径的模拟器页面安装样本约 0.9–3.3 ms，该数值不代表真机帧率。
- Web 实际导入两章 TXT，50 px 短滑可跨章；菜单打开后再次翻页，菜单自动收起。点击左侧可回到本章上一页。
- 左下显示整书当前页 / 总页数，右下显示时间和可读取的真实电量。进度条按页加权，已排版章节采用实测页数，其余根据已有正文与排版估算；总页数可随字体、视口和缓存变化。跨设备仍同步 UTF-16 文字位置。

## 已知验证边界

- Android 的文件选择、系统返回、后台行为与长时间阅读仍需模拟器或真机验证；CI 成功不能替代设备测试。
- 本轮工作流自动化使用受控测试数据；实际书源的章节命名、目录变动和网络条件仍需使用中验证。自动匹配不唯一时要求用户选择章节，不保证不同版本正文逐字一致。
- iPhone 的长时间锁屏听书、更多音色的实际听感和复杂手势冲突仍需持续体验。Web 电量、系统语音与后台播放取决于浏览器能力。
- 相邻章未缓存时仍需要等待网络。书源改版、内容完整性及海外大文件传输不作全量稳定性保证。
- EPUB 当前按文本重新排版；复杂版式、图片和脚注跳转尚未完整还原。
