## HarmonyOS 原生能力

固定 `https://localhost/` 资源白名单与 TLS 拒绝策略保持启用，不启动本地服务器，不将 API 或凭据交给资源拦截器。v2 WebMessagePort 仅交给固定来源主文档，随机握手、请求白名单、消息/并发/速率限制与文档世代检查限制原生调用。旧宿主按探测到的能力降级。

在官方 CLT 26.0.0.851 / Hvigor 6.26.8 工具链与 HarmonyOS 7.0.0 模拟器实际验证：

- 系统选择器导入 EPUB、PDF、TXT，分类封面与阅读页面正常；覆盖安装保留书架和位置。
- 安装身份显示 0.12.0（2），电量来自系统；设备存在的离线女声能播放与结束，未安装男声不会列成可用音色。调速在下一短句生效。
- ASSET 固定槽在隔离诊断 App 使用合成值完成写入、读取与清除；未读取真实账号会话。保存失败不降级为明文持久存储。
- 系统 SavePicker 保存 4,277 字节备份后，原字节 SHA-256 一致；再次取消未新增文档，暂存清空。大备份分块主动节流，原生限流未放宽。

隔离诊断 App 使用临时合成账号与一本公版书的首章，实际登记系统下载、进入后台、返回后读到完整 15,996 字节，与独立 HTTPS 参考文件的 SHA-256 一致；确认后清除原生暂存和系统任务。排查中发现有界 Range 请求不适用于动态 NDJSON 接口，已移除该请求，暂停后继续仍完整重下；没有为此改变服务端接口。

后台下载和本地提醒使用不同系统机制：request.agent 仅传输当前账号已准备的云任务文件，返回前台校验后导入；WorkScheduler 只做有限目录检查。API 23 以下不启用后台检查，通知默认关闭、由用户主动授权。系统长期调度、强制退出与耗电仍需真机观察。细节见[平台工作流](reading-workflows.md)。

系统听书在切后台时暂停，不声明锁屏播放、Melo / Kokoro 或 AGC 远程 Push 能力。未签名模拟器 HAP 不作为朋友可直接安装的发行包。

## 共用界面与 iPhone 回归

实际浏览器在 390 × 844 检查分类封面、阅读翻页、退出阅读后的滚动恢复、设置滚动位置、关于清读、账号恢复与下载空状态。可见六张封面均完成加载且 naturalWidth 大于零。退出文字或 PDF 阅读后的滚动锁由单一持有者管理，保留生命周期回归。

iPhone 以最终 0.12.0 / build 16 资源编译成功。专用模拟器完整十屏预览通过，原有存储、封面、离线 AI、听书、阅读页、段落命中及前后跨章布局断言保留并通过；分类页另外确认九张可见来源封面加载完成。本轮没有操作真机数据。

## 自动检查

- 宿主 Python：`python3 -m unittest discover -s scripts -p 'test_*.py' -v`，59 项通过，覆盖资源打包、版本清单、签名续签保护和模拟器命令诊断。
- Web：完整测试 264 项通过、4 项真实书源检查按既定条件跳过，TypeScript 与两套最终构建通过。覆盖大备份节流、下载两遍校验、账号切换和配置失败重试，手动与自动导入不会重复执行。
- HarmonyOS：`node --test harmony/tests/*.test.mjs` 共 33 项通过，覆盖资源来源、桥接、语音、安全存储、备份、后台传输、追更隔离与预算；官方 SDK 编译独立执行，不以宿主 mock 代替实际编译。

模拟器 CI 总时限由 20 分钟调整为 30 分钟，并记录命令耗时及脱敏、限长错误尾部。单命令时限、恢复次数、设备选择与阅读断言保持原样，不通过跳过检查处理冷启动超时。

## 发布核对

本轮使用独立静态目录暂存，核对完整文件清单后才切换 `qingread-current`。API 镜像、数据库、共享 Caddy 与 Compose 不属于本轮更新对象。最终应对比发布前后全部容器的 ID、启动时间、重启次数、健康与 OOM 状态，复核清读路径、根路径 404、课程及其他服务原入口。

Android 长期升级包需要在私有环境沿用固定证书，并核对 CI 产物中非 Web 条目、包名、版本、ZIP、v2/v3 签名及公网全字节哈希。公开 CI 使用临时调试签名；固定私钥、密码、签名备份及个人服务配置不提交仓库。

本地清理仅针对可重建产物与本轮重复暂存。保留用户备份、签名、自动续签副本、当前交付 HAP、官方工具链、模拟器镜像与数据。具体边界见[本地维护](maintenance.md)，发布和安装流程见[部署基线](../web/deploy/DEPLOYMENT.md)及[客户端更新](app-updates.md)。
