- 容器使用生产内存限制完成真实 HTTP 上传/下载。公网 HTTPS 再验证 TXT、EPUB、PDF 原字节一致、独立登录会话恢复阅读位置、未登录拒绝、另一账号即使知道相同书籍 ID 与哈希仍无法下载。仅清理本次生成的两个测试账号，保留真实账号。

## 0.3 更新

- ReadingCore 26 项回归通过，新增详情页封面元数据、相对 URL、延迟图片属性和占位图过滤测试。
- 真实模拟器隔离存储诊断通过：旧位置迁移、跳过章节不标已读、完成章节不回退、共享下载去重、自动缓存后 10 章、清缓存取消未完成正文写入，以及目录请求的缓存世代保护。
- 封面缓存诊断通过：首次网络只请求一次，后续内存命中；新实例复用磁盘缓存，生成最长边 480 像素缩略图，并带正确 Referer。实际书源《超神机械师》搜索不含图，详情页 `og:image` 给出 `/uploads/novel/...jpg`，已覆盖该真实缺图路径。来源没有图或网络失败时仍显示排版封面，未承诺所有书都有原图。
- 整书进度映射 34,782 组往返检查通过；UIKit 验证了真实文字 seek、字号重排、7432 UTF-16 单元连续分页以及旧设置迁移。整书百分比按各章等权估算，未抓取全书字数；章节只记录实际访问的最大进度，翻过章尾或自然听完才明确标记完成。
- 通过 Device Hub 实际调用正文的显示菜单动作并打开目录：可见整书 slider 与左侧目录中的「已读／已缓存」状态。触摸拖动与边缘手势仍需真机体验，不能用辅助功能动作代替该验证。
- 语音纯 Swift 测试通过：UTF-16 当前词续读、emoji／组合字边界、旧回调过滤、暂停修改设置、音色优选、短句分块和 PCM WAV 输出。系统 TTS 调速会替换当前词起的余下文字；Melo 调速直接改变当前播放器的 rate，不重新生成当前句。
- 可选声库使用固定官方 Sherpa-ONNX 1.13.8、ONNX Runtime 1.28.2 与 Melo 中文 INT8，六文件共 60,480,445 字节，逐项校验大小与 SHA-256；不完整清单与损坏内容的诊断通过。中断遗留暂存目录在下一次初始化清理，暂存和已完成模型均排除备份。
- 模拟器已经实际执行 App 内的完整下载与校验，并在本地生成《桃花源记》短句。首次模型加载、合成与 PCM 编码合计 3.372 秒，输出 44.1 kHz、106,689 个有限采样；保存真实 WAV。播放器语速更改位置不回退、暂停／继续、停止取消和旧回调失效检查通过。这个耗时来自 Mac 上的模拟器，不代表目标 iPhone 的速度。
- 模型和推理都在同一个 App 内；只有首次下载访问 Hugging Face，合成不调用 API、不上传文字。音质为单一 Melo 音色，需要用户试听，未宣称达到商业云端有声书的情绪和角色表现。
- arm64 真机干净构建与严格签名校验通过。用户切到个人热点后，0.3.0（build 3）无线覆盖安装并启动成功；更新前后两本书的书架 JSON（包含阅读位置）逐项一致。本轮没有在手机上强制下载声库或启动长时间音频，真实音色与锁屏连续性仍由用户体验确认。

本轮额外查看了预编译依赖的实际 archive 组成，GPL／MPL 等许可与原始声明保存在随包资源中，细节见 [offline-voice.md](offline-voice.md)。
