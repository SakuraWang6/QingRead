## 本地自动化与原生诊断

- Swift 核心最终 **13 项 XCTest、38 项 Swift Testing 通过**。覆盖后台批次的紧凑载荷、重连和限频延期，书架整理与笔记合并，以及 EPUB 安全资源、脚注和 PDF UTF-16 页内锚点。当前使用 Swift 5，SDK 的部分并发检查仍有迁移警告。
- 原生存储自检的章节工作流、后台批次、书架元数据、文件导入和缓存组全部通过：包括换源失败原子性、旧阅读器保护、账号隔离、暂停与迟到响应、清缓存失效、去重和历史上限。
- 原生 UIKit 阅读器的滑动／覆盖模式、跨章、排版和文字位置自检通过；听书核心检查通过 UTF-16、组合字符、短句与 PCM WAV，定时停止检查通过。续签安全回归 **34 项通过**。
- PDF/EPUB、出版物和推送的针对性 Web 测试 **26 项通过**。不调用外网目录、OCR 或真实设备推送；通知发送使用注入的测试函数。PDF 搜索覆盖分开的中文绘制 run、字面匹配、100 条上限、取消和代理对安全截断。
- 最终 Web 全量在允许本机监听的环境复跑，**178 项通过、4 项实时来源测试跳过，共 28 个文件（27 通过、1 跳过）**。先前受监听权限影响的启动子进程检查已通过。常规测试不依赖真实书源，实时测试跳过不代表原站可用。
- 真实浏览器已验证书架整理、笔记与缓存搜索；EPUB 脚注往返最终复验待补。

## 本轮功能边界

- 书架置顶、分组、阅读状态和逐条笔记随账号同步；进度不清空元数据，笔记删除保留标记。来源切换需要当前修订号，旧源进度不能回滚新源。密码修改与恢复撤销旧会话，恢复码只存哈希、使用一次。
- 本机缓存正文搜索与 PDF 文字搜索不上传全文。PDF 使用共同的页 ID，PDFKit/PDF.js 的文字提取可能不同，跨端可靠定位为原始页码；Web canvas 没有正文 text layer 选择或高亮。
- EPUB 原版真实显示本书资源、标题层级与脚注往返，禁用作者脚本与外网；原版物理滚动位置仅本地保存，文字模式的 UTF-16 位置继续同步。不是所有特殊版式都已验证。
- iPhone 原生通知是系统允许的后台检查之后的本地通知，免费个人签名不支持 APNs。iOS 16.4+ 主屏幕 PWA 可使用登录后主动授权的 Web Push，但服务器网络、权限、专注模式和节电策略影响送达；本轮未向真实手机发送测试通知。
- 浏览器关闭页面后，云端准备可继续，正文仍需回前台保存到设备。iPhone 后台传输与后续批次衔接受系统控制；Android 前台服务与 WorkManager 的熄屏、强制停止、超时和厂商省电行为尚无真机验证。

## 安装与部署

- iPhone 升级前备份 **850 个 App 数据文件，约 10.7 MB**；最终 0.10.0/build 12 严格签名校验、保留数据覆盖安装、启动与版本核对通过。续签运行副本的版本、build 与已安装二进制一致。
- 开发机已构建包含 `web-push` 生产依赖的 `linux/amd64` API 镜像，运行时导入检查通过，开发机到 Apple 推送端点的 TLS 连接返回预期的未授权方法响应；这不代表生产服务器实际送达验证。不再沿用 0.9 仅复制源码的依赖不变方案。
- 本轮子路径 Web、账号隔离、云端准备、推送配置、公网资源及共享服务器状态的最终结果待维护者补齐。发布必须只更新清读，保留共享 Caddy/Compose 路由、其他项目与上一兼容版本；见[部署基线](../web/deploy/DEPLOYMENT.md)。
- Android 最终 CI、固定升级证书、manifest 版本、ZIP 完整性与下载 SHA-256 待最终产物核对。公开 CI 用临时调试签名，不提供个人签名密钥。

## 仍需实际设备验证

Android 尚无模拟器或真机运行结果；CI 成功不能代替设备测试。iPhone 长时间锁屏听书、后台任务调度与通知送达需持续体验；Web 电量、系统音色和后台播放取决于浏览器能力。未缓存章节仍需等待网络，书源改版、目录完整性和海外大文件传输不作全量稳定保证。图片型 PDF 无 OCR，PDF 不支持听书。
